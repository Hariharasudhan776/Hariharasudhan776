### A thing I care about

A resume generator I built refuses to print a skill the profile cannot evidence — not
because a prompt asks it politely, but because the check runs in code and the document
is graded afterwards. I would rather a tool tell me I am missing something than flatter
me. The same instinct is why `pg-perf-lab` generates its own benchmark output: a claim
you cannot reproduce is not a claim.
